# M1 — Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a running Next.js + TypeScript + Tailwind app, with lint/typecheck/test/check scripts wired together, a local-only Git repo, and a bottom tab bar linking four empty pages (Today, Tasks, Chart, Settings).

**Architecture:** Scaffold with `create-next-app` (App Router, TypeScript, Tailwind, ESLint) into the existing project folder without clobbering the curated `README.md`/`CLAUDE.md`/`docs/`. Add Vitest and a `typecheck` script on top of the scaffold's own `lint` script, composed into one `check` script. The tab bar's route-matching logic is a small pure function so it gets a real Vitest test without pulling in a DOM-testing library this early.

**Tech Stack:** Next.js (App Router), React, TypeScript (strict), Tailwind CSS, ESLint (eslint-config-next), Vitest, npm.

**Spec:** [docs/spec.md](../../spec.md), section 13 "M1. Skeleton"; data model and project structure also come from [CLAUDE.md](../../../CLAUDE.md).

## Global Constraints

- $0 running cost: only free tiers / open-source packages ([CLAUDE.md](../../../CLAUDE.md) "Hard rule").
- Local only for now: local Git only, no remotes, no GitHub, no CI, no hosting setup.
- TypeScript strict mode, no `any`.
- Ask before adding any new dependency (name it, its license, confirm it's free) — applies to Vitest itself and anything else introduced in this milestone.
- `.gitignore` must cover `node_modules`, `.next`, and `.env*`; the only secret (`GROQ_API_KEY`) is never committed.
- Mobile-first layout; tap targets at least 44px; accessible color contrast; semantic HTML.
- `npm run check` (lint + typecheck + test) must pass before the milestone is considered done, and the milestone ends with a local Git commit.

## Review Focus

- A route one level deeper than a tab's own path (e.g. a future `/tasks/123`) must still highlight the `Tasks` tab, not fall through to no active tab — covered by `isActiveRoute`'s tests in Task 3.
- The root route (`/`) must only be "active" for `/` itself, not treated as a prefix of every other route — covered by `isActiveRoute`'s tests in Task 3.
- `.env.local` must actually be excluded from Git by the generated `.gitignore`, not just assumed — verified explicitly in Task 1.
- The Node.js version on this machine must meet the current Next.js floor before scaffolding, or `create-next-app` fails confusingly mid-way — checked at the start of Task 1.
- Tap targets in the bottom tab bar must be at least 44px, which isn't something a Vitest unit test can check — called out as a manual verification step in Task 3.

**Interfaces:**
- Produces: `TABS: { label: string; href: string }[]` — the four tabs, in order: `{ label: "Today", href: "/" }`, `{ label: "Tasks", href: "/tasks" }`, `{ label: "Chart", href: "/chart" }`, `{ label: "Settings", href: "/settings" }`.
- Produces: `isActiveRoute(pathname: string, href: string): boolean` — `true` when `pathname === href`, or (for every `href` other than `"/"`) when `pathname` starts with `href + "/"`. `"/"` only matches `pathname === "/"` exactly, never as a prefix.
- Consumes (in `BottomNav.tsx`): `TABS` and `isActiveRoute` from `src/lib/nav.ts`, and `usePathname` from `next/navigation`.

- [ ] **Step 1: Write the failing tests for `isActiveRoute`**

```ts
// src/test/nav.test.ts
import { describe, it, expect } from "vitest";
import { isActiveRoute, TABS } from "@/lib/nav";

describe("isActiveRoute", () => {
  it("matches the root route only when the pathname is exactly /", () => {
    expect(isActiveRoute("/", "/")).toBe(true);
    expect(isActiveRoute("/tasks", "/")).toBe(false);
  });

  it("matches a non-root tab exactly", () => {
    expect(isActiveRoute("/tasks", "/tasks")).toBe(true);
  });

  it("matches a non-root tab's sub-routes as a prefix", () => {
    expect(isActiveRoute("/tasks/123", "/tasks")).toBe(true);
  });

  it("does not match an unrelated route", () => {
    expect(isActiveRoute("/chart", "/tasks")).toBe(false);
  });

  it("does not match a route that merely shares a prefix string", () => {
    expect(isActiveRoute("/tasksmanager", "/tasks")).toBe(false);
  });
});

describe("TABS", () => {
  it("lists Today, Tasks, Chart, Settings in that order", () => {
    expect(TABS.map((t) => t.label)).toEqual(["Today", "Tasks", "Chart", "Settings"]);
  });
});
```
