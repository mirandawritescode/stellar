The app's foundation: a running Next.js project, local version control, and the four-tab shell every later screen hangs off of.

M2

Onboarding

Done

Collects and saves the three facts the whole app runs on: birth date, birth time, and birth place.

  • Three-step flow at /onboarding — birth date, birth time (exact / rough window / unknown), birth place — with Back/Next and per-step validation
  • /api/geocode server route proxying OpenStreetMap Nominatim, throttled to 1 request/second, with attribution shown in the UI
  • Real IANA time zone resolved for every search result via tz-lookup
  • Finishing onboarding saves BirthData to localStorage and redirects to the Chart page; revisiting the app later skips onboarding automatically

Caught & fixed

  • A first attempt at the "skip onboarding if already set up" check used React's useSyncExternalStore — it had a genuine race condition on this Next.js canary build and incorrectly redirected back to onboarding even with saved data. Reverted to a simpler pattern, verified correct in both directions.
  • .gitignore's bare .env* rule was also silently excluding .env.example, which the spec requires to be committed — added an exception

M3

Chart

Done

The real natal chart: actual planet positions, houses, and aspects, computed from the saved birth data — not placeholder text.

  • Natal chart calculation wrapping circular-natal-horoscope-js — exact, approximate (window-midpoint), and unknown-time rules; ambiguous-Moon detection; aspect calculation using the spec's exact orb rules
  • Fixture tests against two real, birth-certificate-verified charts — Barack Obama and Princess Diana — cross-checked against Astro-Databank data
  • Chart page rebuilt around the real computed chart: Simple and Detailed views, "Estimated" badges, ambiguous-Moon display

Caught & noteworthy

  • circular-natal-horoscope-js's license was assumed MIT going in; it's actually Unlicense (public domain) — corrected, still free
  • The spec called for Luxon to convert local time to UTC; the chart library already does that internally from latitude/longitude, verified correct against both fixtures to the arc-minute — so Luxon sat unused for this specific piece (kept installed for M4/M5, where it's still needed)
  • The ambiguous-Moon badge triggered organically during manual testing — on Obama's actual birth date, the Moon really does cross from Taurus into Gemini — rather than only in a synthetic test
